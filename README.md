# 🐾 PetShop Amigo Animal

Site institucional e de e-commerce desenvolvido para um petshop completo, com foco no bem-estar animal. O projeto apresenta os serviços, produtos e informações da empresa de forma clara, responsiva e interativa.

🔗 **Acesse o site:** [joaopaulomenezes01.github.io/ProjetoPetshop](https://joaopaulomenezes01.github.io/ProjetoPetshop)

---

## 📋 Sobre o Projeto

O **PetShop Amigo Animal** é um projeto web desenvolvido com tecnologias front-end puras, simulando um ambiente real de loja virtual para pets. O objetivo foi criar uma experiência de navegação fluida e agradável, com páginas dedicadas a cada área do negócio.

---

## 🚀 Funcionalidades

- **Página Inicial** — Apresentação da empresa com diferenciais e informações de contato
- **Sobre Nós** — História, missão e valores da empresa, além da apresentação da equipe
- **Serviços** — Catálogo de serviços com descrições e preços (Banho e Tosa, Vacinação, Adestramento, Hospedagem e mais)
- **Produtos** — Loja virtual com categorias de Rações, Brinquedos, Produtos de Banho e Remédios
- **Carrinho de Compras** — Funcionalidade interativa para adicionar e remover itens, com cálculo automático do total
- **Notificações** — Feedback visual ao adicionar produtos ao carrinho

## 📄 Páginas

### 🏠 Início
Apresentação do petshop com os principais diferenciais: Qualidade Garantida, Cuidado com Amor e Melhor Atendimento.

### 📖 Sobre Nós
História da empresa, missão institucional e apresentação da equipe de profissionais, incluindo veterinários, tosadores e adestradores.

### 🛁 Serviços
Catálogo completo com 6 serviços disponíveis:
- Banho e Tosa
- Tosa Higiênica
- Limpeza Dentária
- Vacinação
- Adestramento
- Hospedagem

### 🛒 Produtos
Loja virtual organizada em 4 categorias:
- **Rações Premium** — Royal Canin, Whiskas, Natural Balance
- **Brinquedos** — Bola Sonora, Arranhador, Mordedor Dental
- **Banho & Tosa** — Banho Simples, Banho Premium, Pacote Mensal
- **Remédios** — Antipulgas, Antibiótico, Multivitamínico

## ⚙️ Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/joaopaulomenezes01/ProjetoPetshop.git
```

2. Acesse a pasta do projeto:
```bash
cd ProjetoPetshop
```

3. Abra o arquivo `index.html` no seu navegador.

> Não é necessário instalar dependências. O projeto roda diretamente no navegador.
